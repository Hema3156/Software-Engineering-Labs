# Software Engineering Labs

## About

This repository contains my Software Engineering lab assignments, practical exercises, project work, and supporting documentation. The labs cover requirements engineering, Agile project management, software architecture, application prototyping, and software testing.

## Lab Overview

### Lab 1 — Requirements Engineering & UML Use-Case Modelling

**Problem Statement:** Hostel Maintenance & Issue Ticketing System  
**Domain:** Campus & Academic Operations

This lab focuses on identifying and documenting the functional requirements of a hostel maintenance system and modelling its interactions using UML use-case diagrams.

**Deliverables:** Lab report and requirements modelling documentation.

### Lab 2 — Agile Backlog Creation & Sprint Simulation in Jira

This lab uses Jira to convert the functional requirements identified in Lab 1 into Agile backlog items.

The work includes:
- Creating epics and user stories
- Prioritizing and estimating backlog items
- Simulating a sprint
- Analysing sprint progress

**Deliverables:** Jira backlog with epics and user stories, along with lab documentation.

### Lab 3 — Component Modelling & Architectural Pattern Selection

This lab focuses on evaluating architectural styles and selecting an appropriate architecture for the assigned system.

The work includes:
- Comparing layered, microservices, and client-server architectures
- Identifying system components and their dependencies
- Creating a UML component diagram
- Documenting architectural decisions, including security and performance considerations

**Tools:** draw.io or another UML modelling tool.

**Deliverables:** Component diagram and architecture justification document.

### Lab 4 — Vibe Coding

This lab focuses on vibe coding and application creation with AI-assisted development.

The repository contains before-and-after video files documenting the work.

**Deliverables:** Before-and-after demonstration videos.

### Lab 5 — Static Code Analysis

This lab focuses on analysing the quality and security of a campus shuttle management application.

The work includes:
- Analysing Python source code
- Identifying code quality issues
- Running static analysis and security checks
- Reviewing reports from Pylint, Flake8, and Bandit

**Deliverables:** Source code, static analysis reports, and lab report.

### Lab 6 — Code and Branch Coverage Analysis

This lab focuses on testing a hospital triage priority application using Python, Pytest, and Coverage.py.

The work includes:
- Writing test cases for code coverage
- Writing test cases for branch coverage
- Measuring test coverage
- Recording terminal results

**Reported results:** 100% code coverage and 100% branch coverage.
